Interval Enclosure

A Rust library for verified numerical computation. Every result is an interval that is guaranteed to contain the true value, not just a small error estimate.

Rust, MIT licensed. Source on GitHub.

Guaranteed bounds on the integral of x² from 0 to 1

With JavaScript off, here is the result for n = 65 536 panels: lower bound 0.333333333294, upper bound 0.333333333334. The exact value, 1/3, is inside.

The highlighted digits are the ones shared by the lower and upper bound, so no rounding error can change them. The same method is behind the Rust demo further down the page.

What it does

Ordinary floating-point code returns a number and hopes it is close to the truth. This crate returns an interval that is guaranteed to contain the exact answer. It tackles two problems:

  • Certified quadrature. Midpoint, trapezoidal, Simpson and Gauss–Legendre rules, with rigorous error bounds obtained through interval arithmetic, plus adaptive integration with error control.
  • Certified ODE integration. Enclosures of solutions of first-order systems using Taylor models, following Florian Bünger [1]. A Taylor model pairs a polynomial with an interval remainder, so a whole set of solutions can be propagated with guaranteed error bounds.

How it works

Interval arithmetic

Real numbers are replaced by intervals, and every operation rounds outward, so the computed interval always contains the true mathematical value [2], [3]. The crate uses the inari library with an MPFR/GMP backend for this.

Quadrature

Following Gautschi [5], Gauss–Legendre nodes are the eigenvalues of the Jacobi matrix built from the Legendre recurrence coefficients (the Golub–Welsch algorithm), and the weights come from the eigenvectors. Reference values for orders 5, 10 and 20 come from the DLMF [4].

Each rule has a classical error formula. For the midpoint rule on an interval of length b−a with step h it reads

|E|≤(b−a)h224supx|f″(x)|

The crate evaluates the derivative term with interval arithmetic. That turns the usual error estimate into a proven bound: the result is an interval guaranteed to contain the exact integral.

Differential equations

The method follows Bünger [1]. Picard iteration computes the Taylor polynomial p. An ε–δ inflation loop then looks for a remainder E satisfying K(p+E)⊆p+E, which proves the enclosure through Schauder's fixed-point theorem. Preconditioning (parallelepiped and QR) reduces the wrapping effect, and blunting handles near-singular matrices.

Run the Rust version

The crate needs MPFR and GMP, so it cannot run in a browser. This is a self-contained miniature of the same idea using only the standard library: a toy interval type that rounds outward by one unit in the last place, and a certified midpoint rule for ∫01x2dx=13. The final check that 1/3 lies in the enclosure is itself done with intervals.

Press Run to compile it on the Rust Playground, or Edit to change it first. Try a different integrand and see what happens to the error bound.

Current limitations

  • The ODE solver handles first-order systems only; higher-order equations must be rewritten in first-order form.
  • Taylor model versions of the standard functions (exp, sin, cos, and so on) are not fully implemented yet.

Built with

  • inari for interval arithmetic (needs MPFR and GMP)
  • nalgebra for linear algebra (Golub–Welsch)
  • rust-matplotlib for plotting (needs Python and Matplotlib)
