Interval Enclosure

A Rust library for verified numerical computation: results come with a mathematical guarantee, not just a small error estimate.

Overview

Ordinary floating-point code returns a number and hopes it is close to the truth. This crate returns an interval that is guaranteed to contain the exact answer. It tackles two problems:

  • Certified quadrature — midpoint, trapezoidal, Simpson and Gauss–Legendre rules, with rigorous error bounds obtained through interval arithmetic.
  • Certified ODE integration — enclosures of solutions of first-order systems using Taylor models, inspired by the work of Florian Bünger [1].

A Taylor model pairs a polynomial with an interval remainder, so a whole set of solutions can be represented and propagated with guaranteed error bounds.

Features

Certified integration

  • Midpoint, trapezoidal and Simpson rules, each with a rigorous error bound
  • Gauss–Legendre quadrature built with the Golub–Welsch algorithm
  • Adaptive integration with error control (a priority queue refines the subinterval with the largest error estimate)
  • Error terms bounded by evaluating derivatives in interval arithmetic

ODE solving

  • Taylor model arithmetic with rigorous rounding-error tracking
  • Picard iteration for the polynomial part
  • ε–δ inflation to verify the remainder
  • Preconditioning (parallelepiped and QR) to reduce the wrapping effect, plus blunting for near-singular matrices
  • Verified enclosures for interval initial value problems

How it works

Interval arithmetic. Real numbers are replaced by intervals, and every operation rounds outward, so the computed interval always contains the true mathematical value [2][3]. The crate uses the inari library with an MPFR/GMP backend for this.

Quadrature. Following Gautschi [5], Gauss–Legendre nodes are the eigenvalues of the Jacobi matrix built from the Legendre recurrence coefficients, and the weights come from the eigenvectors (the reference values for orders 5, 10 and 20 are taken from the DLMF [4]). The classical error formula of each rule is then evaluated with interval arithmetic on the derivative term, which turns the usual error estimate into a proven bound: the result is an interval guaranteed to contain the exact integral.

ODEs. The method follows Bünger [1]. Picard iteration computes the Taylor polynomial p; an ε–δ inflation loop then looks for a remainder E satisfying K(p+E) ⊆ p+E, which proves the enclosure through Schauder's fixed-point theorem.

Try it in your browser

The crate itself needs MPFR and GMP, so it cannot run on a web page. This demo is a self-contained miniature of the same idea, written with the standard library only: a toy interval type that rounds outward by one unit in the last place, and a certified midpoint rule for ∫₀¹ x² dx = 1/3. The error term uses |E| ≤ (b−a)·h²/24 · sup|f″| with f″ = 2, and the final check that 1/3 lies in the enclosure is itself done with intervals. Edit it and run it; it executes on the official Rust Playground.

Current limitations

  • The ODE solver only handles first-order systems; higher-order equations must be rewritten in first-order form.
  • Taylor model versions of the standard functions (exp, sin, cos, …) are not fully implemented yet.

Tech stack

  • Rust
  • inari for interval arithmetic (requires MPFR and GMP)
  • nalgebra for linear algebra (Golub–Welsch)
  • rust-matplotlib for plotting (requires Python and matplotlib)
