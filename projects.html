Projects

Two of these run on the page: drag a slider, type into a terminal, or edit the Rust and run it.

  • Interval Enclosure: certified numerics in Rust

    Runs in your browser

    A Rust library for verified numerical computation. It computes integrals with rigorous error bounds (midpoint, trapezoidal, Simpson, Gauss–Legendre, adaptive) and encloses ODE solutions with Taylor models, following the approach of Bünger. Every result is an interval guaranteed to contain the true value, thanks to interval arithmetic with outward rounding.

    Rust, interval arithmetic, numerical analysis, verified computation

  • CLI To-Do List in Rust

    Runs in your browser

    A colorful multi-list command-line to-do app, built from scratch while working through The Rust Programming Language. Tasks can be shared between lists, everything saves to JSON, and invalid input becomes an error message instead of a panic. Try it in a terminal on the project page.

    Rust, CLI, error handling, serde

  • Priority Search Tree in Java

    A priority search tree for windowing queries over horizontal and vertical segments, built for the Data Structures II course at UMons. It came with a written report and an oral defense. GitHub profile

    Java, data structures

  • Personal server on a Raspberry Pi 5

    A self-hosted NAS on a Raspberry Pi 5 (8 GB RAM) with a 2 TB SSD. OpenMediaVault manages the storage, Immich backs up photos, and a WireGuard VPN gives secure remote access.

    Linux, self-hosting
