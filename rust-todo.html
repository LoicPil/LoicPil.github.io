CLI To-Do List — Rust

A command-line to-do list built while learning Rust chapter by chapter through "The Rust Programming Language" (the "Rust Book").

Overview

This is my main Rust learning project, extended progressively as I work through the book: structs and ownership first, then enums and pattern matching, modules, collections, and idiomatic error handling with Result. Tasks are stored in a HashMap keyed by a dedicated auto-incrementing ID (kept stable across deletions, unlike indexing into a Vec), and invalid commands or missing IDs are handled through a custom TodoError type rather than panicking. Development follows a Git workflow with feature branches, conventional commits, and a changelog.

Features

  • Add a task
  • List all tasks, or filter by status (Todo / In Progress / Done)
  • Mark a task as in progress or done
  • Remove a task
  • Stable task IDs that persist correctly across deletions
  • Interactive command-line loop (REPL-style)

Tech stack

  • Rust — standard library only so far (no external crates yet)
  • HashMap<u32, Task> for O(1) lookup and removal by ID
  • Custom error handling via a TodoError enum and Result
  • Git — feature branches, conventional commits, Keep a Changelog format

What's next

Currently working through automated testing (unit tests for the core add/complete/remove/filter behavior), with persistent JSON storage and a rewrite of the filtering logic using iterators and closures planned for later chapters.
