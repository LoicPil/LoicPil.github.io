CLI To-Do List — Rust

Une application en ligne de commande développée en apprenant Rust, en suivant le livre officiel "The Rust Programming Language".

Aperçu

Ce projet m'a permis de pratiquer la gestion de la mémoire, le système de types de Rust (ownership, borrowing), ainsi que la persistance de données simples (lecture/écriture de fichiers). Le développement a suivi un workflow Git avec des branches de fonctionnalités (feature branches).

Fonctionnalités

  • Ajouter une tâche
  • Lister les tâches en cours
  • Marquer une tâche comme terminée
  • Sauvegarde persistante dans un fichier local

Stack technique

  • Rust — langage principal
  • Git — versionning avec branches de fonctionnalités
