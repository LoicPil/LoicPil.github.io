CLI To-Do List — Rust

A command-line application built while learning Rust, following the official "The Rust Programming Language" book.

Overview

This project let me practice Rust's memory model and type system (ownership, borrowing), as well as simple data persistence (reading and writing files). Development followed a Git workflow with feature branches.

Features

  • Add a task
  • List pending tasks
  • Mark a task as done
  • Persistent storage in a local file

Tech stack

  • Rust — main language
  • Git — version control with feature branches
