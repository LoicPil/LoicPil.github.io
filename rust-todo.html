CLI To-Do List

A colorful multi-list command-line to-do app, built from scratch while working through The Rust Programming Language. It started as a five-minute Vec<Task> and ended as a tool I can install and use every day.

Rust, MIT licensed, version 1.0.0. Source on GitHub.

How it is built

Errors are values

Every operation that can fail returns a Result. A missing task or list becomes a TodoError that the main loop prints, so bad input never panics.

One task, many lists

On the board, a task lives once and lists only hold its id. The registry stores each task as Rc<RefCell<Task>>, so completing it through any list updates it everywhere. borrow_mut() gives temporary mutable access to the task inside the RefCell.

Ids stay compact

Tasks are stored in a HashMap keyed by a numeric id, and removing a task never renumbers the others. When the most recent task is removed, the counter steps back over any unused trailing ids, so the next task reuses the freed number instead of leaving gaps.

Features

  • Basic list: add, complete, remove, mark in progress, filter by status.
  • Multi-list board: named lists such as "Work" and "Personal", with tasks that can be shared across lists.
  • Persistent: everything saves to JSON in ~/.todo_cli/ and reloads on startup.
  • Styled output: bordered tables, color-coded status, strikethrough for done tasks.
  • Installable: cargo install --path ., then run todo_list from any folder.
  • Tested and documented: unit tests in every module and rustdoc comments.

Commands

Basic list

CommandWhat it does
add <desc>add a new task
done <id>mark a task done
remove <id>remove a task
progress <id>mark a task in progress
listshow all tasks
filter <todo|done|inprogress>show tasks with a given status

Multi-list board

CommandWhat it does
bcreate <list>create an empty list
badd <list> <desc>add a task directly into a list
bdone <id>mark a board task done (visible in every list it's in)
bprogress <id>mark a board task in progress
blistsshow every list's name
blist <list>show tasks in a list
ballshow every list, each with its own header
bassign <id> <list>share an existing task into another list
bunassign <id> <list>remove a task from one list only
bremove <id>remove a task entirely, from every list
bdelete <list>delete a whole list (unassigns its tasks first)
bwhere <id>show which lists contain a task
bimport <id> <list>move a task from the base list into a board list

Also: help or ? shows the help, and quit saves and exits.
